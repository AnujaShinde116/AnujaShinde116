- **CogR-VOS** (capstone, ongoing): co-developing a training-free pipeline that keeps a language-referred target's identity through occlusion and look-alikes, using frozen Grounding DINO, SAM 2.1, DINOv2, CLIP and the Gemini API. Five versions (V0 to V4) evaluated on Ref-DAVIS17 (J&F 50.48 to 50.97), with event-triggered VLM calls about 52x fewer than querying every frame. I'm also writing the research paper.
- **ReFyn**: schema-agnostic ETL pipeline that maps arbitrary marketing CSV columns, cleans and deduplicates records, computes funnel metrics (ROAS, CPA, CPC, CPM) and flags anomalies and bot traffic. Orchestrated with Airflow and PostgreSQL in Docker, with a Flask/Chart.js dashboard and AI-generated insights via Gemini.
- **Formula 1 Race Winner Prediction (MLOps)**: ML pipeline on 1950–2024 data with leakage-free cumulative win-rate features. Random Forest reached a ROC-AUC of about 0.94, plus a future-season simulation engine.
- **docker-registry-project**: private Docker registry with authentication; secure image push, pull and DevOps workflow on Ubuntu.
